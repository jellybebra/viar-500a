# VIAR-500A в Astra Linux

[![Build and release DEB](https://github.com/jellybebra/viar-500a/actions/workflows/release.yml/badge.svg)](https://github.com/jellybebra/viar-500a/actions/workflows/release.yml)

## Основное приложение «Сканер VIAR»

Для повседневной работы используется адаптированный
[Camscan](https://github.com/suhren/camscan) 0.2.1. Это отдельный интерфейс,
который работает напрямую с V4L2 `/dev/video0` и закрывает функции фирменной
Windows-программы:

- живой предпросмотр максимального режима `2592x1944 @ 2 fps`;
- непрерывный прогрев камеры и аппаратного баланса белого;
- поиск небольшого светлого листа на тёмном поле;
- семь режимов размера: авто с перспективой, авто без перспективы,
  пользовательская рамка, несколько объектов, A3, A4 и A5;
- автоматическая обрезка и исправление перспективы каждого найденного листа;
- автоматический поворот одиночного A4;
- отдельная PDF-страница для каждого листа в режиме нескольких объектов;
- очередь страниц с изменением порядка и удалением;
- цвет, оттенки серого, чёрно-белый режим и запасная коррекция белого;
- локальная бинаризация Sauvola с регулируемым сохранением бледного текста;
- обработка фиксируется в момент сканирования и не меняет готовые страницы;
- явное применение текущей обработки ко всем ранее снятым страницам;
- управление яркостью, контрастом, балансом белого, экспозицией и другими
  аппаратными параметрами VIAR через V4L2;
- закреплённые кнопки сканирования и сохранения PDF, доступные без прокрутки;
- сохранение всех набранных страниц одним PDF.

## Установка одним файлом

Свежий автономный пакет находится в разделе
[Releases](https://github.com/jellybebra/viar-500a/releases/latest).

```bash
sudo apt install ./viar-scanner_0.4.4_amd64.deb
```

Python, OpenCV contrib, NumPy, Pillow, CustomTkinter и ресурсы интерфейса уже
находятся внутри пакета. Системные X11/Tk-библиотеки берутся из графической
среды Astra, чтобы не смешивать ABI Ubuntu и Astra. Интернет и отдельная
установка Python-пакетов на рабочем месте не требуются.

После установки откройте в меню приложений **«Сканер VIAR»**. Первые восемь
секунд кнопка «Сканировать» заблокирована: в это время камера непрерывно выдаёт
кадры и аппаратный автоматический баланс белого успевает стабилизироваться.
Максимальный режим камеры физически ограничен двумя кадрами в секунду, но
распознавание и обработка предпросмотра выполняются в отдельном потоке и не
блокируют кнопки и окна приложения.

Обычный порядок работы:

1. Положить лист на тёмное поле и дождаться зелёной рамки по его краям.
2. Выбрать «Размер». В пользовательском режиме протянуть рамку мышью по
   предпросмотру.
3. Нажать «Сканировать» или клавишу `Пробел`.
4. Повторить для остальных листов; миниатюры появляются справа.
5. При необходимости повернуть, поменять порядок или удалить страницы.
6. Нажать «Сохранить PDF». Диалог откроется в папке, куда PDF сохранялся
   в прошлый раз.

Программа запоминает для каждого пользователя тему и масштаб интерфейса,
последнюю папку PDF, размер страницы, режим обработки, настройку сохранения
бледного текста, автоповорот, источник и разрешение камеры, а также формат
отдельных изображений. Уже отсканированные страницы и имя прошлого PDF между
запусками не сохраняются.

Изменение обработки или чёрно-белого порога влияет только на предпросмотр и
следующие сканы. Для намеренного пересчёта уже снятых страниц используется
кнопка «Применить к готовым страницам».

Другие программы, использующие камеру (`guvcview`, `ffplay`),
должны быть закрыты: `/dev/video0` может быть занят только одним процессом.

Удаление приложения:

```bash
sudo apt remove viar-scanner
```

## Ручная диагностика для разработчика

В каталоге `scripts` оставлены три инструмента для разбора проблем без GUI:

- `test-camscan-camera.py` получает реальный кадр с VIAR;
- `test-camscan-pipeline.py` сохраняет промежуточные этапы обрезки и обработки;
- `test-bw-thresholds.py` создаёт варианты Sauvola с разной силой сохранения
  бледного текста.

Они запускаются из окружения с зависимостями приложения и с
`PYTHONPATH=third_party/camscan`.

## Сборка автономного пакета

Сборка выполняется один раз на Astra Linux с доступом к интернету:

```bash
sh scripts/build-standalone-deb.sh
```

Результат — единственный файл `viar-scanner_0.4.4_amd64.deb`. На компьютере,
где будет использоваться сканер, дополнительные зависимости устанавливать
не требуется.

Релиз собирается на базе Debian 10 с `glibc 2.28`, поэтому один и тот же пакет
совместим с Astra Linux 1.7 и более новыми выпусками.

Каждый push в ветку `main` запускает GitHub Actions: workflow собирает
автономный `.deb`, выполняет тесты геометрии и обработки, проверяет встроенные
библиотеки и публикует новый GitHub Release с пакетом и его контрольной суммой
SHA-256.
